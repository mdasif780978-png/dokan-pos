# Example Script + Filled Plan (35–40 s reel)

Original script written in the 5-keys structure: hook → pattern interrupt → 3 chapters → recap.
Topic: "3 steps to land your first video-editing client on Upwork".

| Code | Script line | Plan (design picked) |
|---|---|---|
| L01 HOOK | "Landing your first editing client on Upwork comes down to three simple steps." | Eyes on upper third. Upwork-style glass notification "New offer received — $450" slides down (S04, generic icon unless user supplies logo). Then 3 rhombus badges pop in a row (S02). Caption special word: *first client*. |
| L02 | "The problem is most editors send fifty proposals and hear nothing back." | Pattern interrupt: nose-tracked punch-in, B&W, reverb (S08). Caption special word: *nothing*. |
| L03 | "Step one: build a portfolio that proves one style." | Snap back to color. Badge 1 + "Prove *one* style" (S03). |
| L04 | "Clients don't hire 'I can edit anything.' They hire the editor who already made the video they want." | Out-of-screen zoom-out (F01): A-roll shrinks, messy mixed-style thumbnails around it → pan to one clean 3-reel portfolio card (F02). |
| L05 | "Step two: write proposals about their video, not about you." | Badge 2 + "Their video, *not* you" (S03). |
| L06 | "Open with what you'd change in their first ten seconds." | Before → After (S07): generic "Hi, I'm an editor…" proposal → specific "Your hook loses viewers at 0:04, here's the fix". |
| L07 | "That one line doubles your reply rate." | Ring counter 0→2× (S05). |
| L08 | "Step three: over-deliver on the first job." | Badge 3 + "*Over-deliver*" (S03). |
| L09 | "Deliver early, add one free thumbnail, and ask for the review." | Glass list (S06): ✓ Deliver early · ✓ Free thumbnail · ✓ Ask for review. |
| L10 | "Do that, and clients start coming back on their own." | Full-screen text "coming *back*" on royal blue (F05) → radar with client nodes (F08). |
| L11 | "Portfolio, proposals, over-deliver. That's the whole system." | Back to A-roll, recap pills stack up (O01), music swell and fade. |
